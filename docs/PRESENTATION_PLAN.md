# 🎤 แผนนำเสนอ Senior Project — พี่เงิน (AI Finance Coach)

> Bestimove Academy · ทีม 3 คน · แผนสำหรับนำเสนอ/เดโมต่อกรรมการ
> เป้าหมาย: ให้กรรมการเห็น **ปัญหาจริง → ทางแก้ที่ใช้ได้จริง → ของเด็ดที่ทำได้** ในเวลาจำกัด

## ⏱️ โครงเวลา (ปรับตามเวลาที่ได้ — ตัวอย่าง 15–20 นาที)

| ช่วง | เวลา | ใคร | เนื้อหา |
|---|---|---|---|
| 1. เปิด + ปัญหา | 2 นาที | แตงกวา | ปัญหาคนรุ่นใหม่จัดการเงิน + ทำไมแอปเดิมไม่เวิร์ก |
| 2. ทางแก้ + ภาพรวม | 2 นาที | แตงกวา | พี่เงินคืออะไร + จุดต่างจากแอปทั่วไป |
| 3. **เดโมสด** ⭐ | 6–8 นาที | ต้า (จอ) + โดม (พูด) | โชว์ของจริง (สคริปต์ด้านล่าง) |

## 🎬 สคริปต์เดโมสด (หัวใจของการนำเสนอ — ซ้อมให้ลื่น)

> เตรียม: backend รันอยู่ + มี LLM key (Groq/Typhoon) + บัญชีเดโมมีข้อมูลตัวอย่าง + ใบเสร็จจริง 1 ใบไว้ถ่าย
> **เรียงจาก "ว้าว" ไปหา "ครบ"** — เอาของเด็ดขึ้นก่อน

**① จดเงินด้วยภาษาคน (30 วิ)** — พิมพ์ในแชท `ก๋วยเตี๋ยว 55` → เด้งการ์ด "จดสำเร็จ" หมวดอาหารทันที
> พูด: "ไม่ต้องกดฟอร์ม 5 ช่อง พิมพ์เหมือนคุยกับเพื่อน พี่เงินจดให้เลย"

**② คุยกับ AI ที่รู้ข้อมูลเราจริง (1 นาที)** — ถาม `เดือนนี้ใช้ค่าอาหารไปเท่าไหร่` → ตอบจากข้อมูลจริง
> พูด: "AI ตัวนี้ไม่ได้มั่ว มันดึงข้อมูลจริงของผู้ใช้มาตอบ (function calling)"

**③ สแกนใบเสร็จแยกรายการ (1.5 นาที)** — ถ่ายใบเสร็จ 7-11 → แตกเป็นหลายรายการ + การ์ดหลายใบ
> พูด: "ใบเดียวได้หลายรายการ แถมแยกยอดรวม/VAT ออกให้"

**④ กันพลาด: เอกสารสัญญา (30 วิ)** — ถ่ายใบสัญญาผ่อนรถ → พี่เงินรู้ว่าไม่ใช่ใบเสร็จ ไม่จดมั่ว แต่แนะให้จดเงินดาวน์
> พูด: "AI ฉลาดพอที่จะรู้ว่าอันไหนไม่ควรจด"

**⑤ แก้/ลบได้ในตัว (30 วิ)** — กดปุ่มแก้ที่การ์ด → เปลี่ยนหมวด/ยอดได้เลย

**⑥ ปิดด้วยภาพรวม (1 นาที)** — โชว์ Dashboard + กราฟ + พยากรณ์เงินคงเหลือ + เป้าออม
> พูด: "จากข้อมูลที่จดง่าย ๆ กลายเป็นภาพรวมการเงิน + AI ทำนายอนาคตได้"

> **แผนสำรอง:** ถ้าเน็ต/LLM ล่มระหว่างเดโม → มีวิดีโออัดหน้าจอไว้เปิดแทน (อัดล่วงหน้า!)

## 💡 จุดขายที่ต้องเน้น (พูดให้กรรมการจำ)

1. **ลดแรงเสียดทาน** — จดเงินง่ายเหมือนแชท (ปัญหาใหญ่สุดของแอปการเงิน = คนขี้เกียจจด)
2. **AI ที่ลงมือทำได้จริง** — ไม่ใช่แค่ตอบคำถาม แต่ "จด/ค้นหา/แยกใบเสร็จ" ให้
3. **ออกแบบให้ไม่พัง** — ไม่มี AI ก็ยังใช้ได้ (rule-based fallback), ไม่มีเน็ตก็จดได้ (offline)
4. **ปลอดภัย** — กันหลุดกรอบ, ไม่แนะนำหุ้นรายตัว, มี disclaimer

## 🏗️ ส่วนเทคนิค (โดมพูด — 3 นาที)

- **สถาปัตยกรรม 3 ขา:** Mobile (Flutter) ↔ Backend (Node/Prisma) ↔ AI (FastAPI/Prophet) + LLM chain
- **AI ทำงานถูกวิธี:** คำนวณตัวเลขด้วยโค้ด ให้ LLM แค่เรียบเรียง (ไม่ปล่อยให้ AI มั่วตัวเลขเงิน)
- **Function Calling:** ให้ LLM เรียกเครื่องมือจด/ค้นข้อมูลจริง
- **ความท้าทายที่แก้:** ความนิ่งของ LLM (ทำ deterministic quick-log), OCR ลายมือ, จัดหมวดอัตโนมัติ
> เตรียม diagram 1 รูป (มีใน `docs/ARCHITECTURE.md` แล้ว) ขึ้นจอตอนพูด

- Scrum 8 sprint × 2 สัปดาห์ · แบ่งงาน: โดม (fullstack+AI) · ต้า (Flutter/UI) · แตงกวา (SE/เอกสาร/ทดสอบ)

## ❓ เตรียมตอบคำถามกรรมการ (ซ้อมไว้)

| กรรมการอาจถาม | ตอบแนวนี้ |
|---|---|
| ต่างจาก app การเงินทั่วไปยังไง | จดด้วยภาษาคน + AI ที่ทำงานให้จริง ไม่ใช่แค่ตารางกรอกเงิน |
| OCR แม่นแค่ไหน | ตัวพิมพ์แม่นดี ลายมือมีข้อจำกัด — ออกแบบให้ผู้ใช้ยืนยัน/แก้ได้เสมอ |
| ความปลอดภัยข้อมูลการเงิน | context ที่ส่ง AI ตัด PII, มี PDPA plan (consent/ลบบัญชี/export) |
| ถ้า AI ตอบผิด/มั่ว | ตัวเลขคำนวณด้วยโค้ด ไม่ใช่ AI + มี rule-based fallback |
| หารายได้ยังไง (business) | freemium / ฟีเจอร์พรีเมียม (พยากรณ์ลึก, รายงาน) |
| ทำต่อได้อีกไหม | มี roadmap: multi-wallet, ธุรกรรมประจำ, LINE bot, gamification |

Part 3 · The subtle one06 / 07
Same reply — but the timing leaked

Data can leak through time, not only content

Email that does not exist
0.16 s
Email that does exist
120 s
700×
Identical messages. A stopwatch tells them apart.

A test that only reads the reply would never catch this. So we added a test that measures time.

In conclusion07 / 07
Tested whether one user can reach another's data.
Tested whether the numbers are exactly correct.
Found 6 real problems — and fixed every one.
Not extra work.
That is the product.

We don't ask users to trust us because we say it's safe — but because we tested it, found six problems, and fixed them.
